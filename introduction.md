# Roadmap de estudos de Backend

Este arquivo reúne os principais temas que serão abordados na Fase 2 da Pós Tech de Full Stack Development na FIAP.

---

## 1. Docker

- Papel dos contêineres no desenvolvimento de aplicações modernas
- O que é Docker
- Por que ele é tão utilizado no mercado
- Como ele ajuda a criar ambientes mais padronizados, portáveis e fáceis de executar
- Gerenciamento de contêineres
- Conceitos iniciais de orquestração
- Boas práticas e estratégias para identificar e resolver problemas comuns

---

## 2. Introdução ao desenvolvimento de APIs

- O que é uma API e por que ela é uma peça central no desenvolvimento full stack
- REST na prática usando Node.js
- Criação de endpoints e organização das requisições
- gRPC com Node.js
- GraphQL com Node.js

---

## 3. Node.js — O princípio

- Construção de aplicações backend com Node.js
- Estrutura de um projeto Node
- Uso do Express como framework para criação de servidores
- Organização de rotas e arquitetura MVC
- Como uma API começa a ser construída, desde a configuração inicial do projeto até a definição das responsabilidades de cada camada

---

## 4. Node.js — Integração com banco

- Persistência de dados e práticas de entrega
- Como conectar uma aplicação Node.js a bancos relacionais, como PostgreSQL
- Como conectar uma aplicação Node.js a bancos documentais, como MongoDB
- CI/CD com GitHub Actions
- Como automatizar etapas importantes do fluxo de desenvolvimento
- Gerenciamento de logs com Prometheus e Grafana
- Documentação de APIs com Swagger e Redoc
- Observabilidade, manutenção e comunicação entre times

---

## 5. Bancos de dados

- Armazenamento, modelagem e performance
- Principais tipos de bancos de dados:
  - relacionais
  - documentais
  - colunares
- Importância dos índices e como eles impactam a performance em bancos relacionais
- Conceitos relacionados a cloud e DBaaS
- Como bancos de dados são utilizados em ambientes modernos, escaláveis e gerenciados

---

## 6. Objetivo do estudo

Compreender os fundamentos e as melhores práticas de backend, com foco em:

- arquitetura de aplicações
- desenvolvimento de APIs
- integração com bancos de dados
- containers e ambientes consistentes
- automação e observabilidade
